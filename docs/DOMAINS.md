# Domain map

This map indexes **production capabilities**, not an exhaustive taxonomy of sciences or a hierarchy of artistic authority. The relationships among formal computation, empirical perception, artistic craft, production organization, historical transmission and presentation are mapped separately in [PROGRAMME](PROGRAMME.md) and [METHODS_AND_QUALITY](METHODS_AND_QUALITY.md).

Stable provisional identifiers denote capabilities rather than applications. The interface branch is kept distinct and linked to graphics at their shared boundaries. Multiple disciplines may contribute to any VG/IP domain; a historical case is evidence about a domain, not its norm.

| ID | Domain | Example output |
|---|---|---|
| VG01 | Raster construction | palette, pixel placement, shading, outlines, resolution/identity tradeoffs, authored raster asset |
| VG02 | Animation and articulation | anatomical base, registered pose library, key poses, multipart animation, prerender-and-correct workflow |
| VG03 | Polygonal construction | modular textured environment, simple lighting and geometry budgets |
| VG04 | Spatial composition | scrolling and parallax, camera sequences, hybrid projection |
| VG05 | Effects | trails, lasers, particles, distortion, procedural geometry |
| VG06 | Illustrative and dramatic composition | environment variants, character illustration, model sheets, adaptation to sprites/portraits/models, directed transitions |
| VG07 | Graphics architecture | logical framebuffer, sampling, world/asset/display proportional contract, priority and blending |
| VG08 | Production infrastructure | asset procurement specifications, source/rights custody, layered handoffs, validation, packing, compilers, editor tooling and diagnostics |
| IP01 | Information architecture / screen composition | layout, hierarchy, character occupancy, viewport and HUD allocation |
| IP02 | Interface states and interaction | navigation, operational contracts, feedback, interruption |
| IP03 | Temporal and audiovisual authorship | motion grammar, easing, sound relations, interpretation |
| IP04 | Interface systems and handoff | editable components, runtime binding, accessibility/localization |
| IP05 | Art direction and economy | choice of treatment, intentional omission, alternatives and critique |

Cross-domain interface: [G02-P01](../research/studies/G02-P01.md) studies the contract between VG01/02/06/07/08 and IP01. It is an upstream authoring-to-runtime capability, not a new silo or a universal resolution mandate.

Tool candidates, not mandates: Aseprite (raster, metadata); Blender (geometry and prerender); Illustrator or equivalent (vectors); Figma or equivalent (states); After Effects or equivalent (temporal prototypes); Clip Studio or equivalent (illustration); Effekseer (effects); Unity (test host); Wwise (audio integration when justified).

Architecture candidates from earlier arcade-board research: explicit sprite/background/polygon/effect processors, logical framebuffer and compositor, distinction between object and display scaling, palette and asset metadata. A 640x480, 4:3, 60 Hz logical display is an experimental candidate only; compare against alternatives and do not impose it on every target. No emulation mandate.
