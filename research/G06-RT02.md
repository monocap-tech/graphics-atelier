## Findings
- Critical: the original charter aims at production capacity. Semantic turn adds real relevant source evidence, particularly documented cross-media transfer and coded distinctions, but semantic analysis is not yet a distinct operational method. We borrow from animation, semiotics, illustration, compositing, interaction and expressive direction (演出). Not necessary to prove professional exclusivity; establish what effects authorship actually decides, and whether framework improves a concrete design or review decision relative to existing practice. Avoid reifying effects as a single kind of object or calling all changes effects.
- High: host categories mix represented existence, spatial dependence, render operation and arity. A tether can be an independent visible object yet depends on two endpoints; an attached aura can outlive its bearer; a screen-space overlay can depict world-space light; an intrinsic-looking transformation may be implemented as two layers. None refutes the usefulness of these distinctions, but they are not mutually exclusive or independent in all cases. Separate represented identity, dependency graph (spatial, causal, temporal), affected property/domain, render mechanism, intended sign or atmosphere, and continuity policy. Do not confuse host with referent: a HUD icon can refer to a remote actor; an independent phenomenon may signify an event elsewhere. Do not add a universal API or taxonomy.
- High: semantic convergence remains unestablished for the chosen game effects. Creator intent, rule documentation, visible motif, audience reading, learned convention and historical lineage are different evidence types. S1–S4 rubric already acknowledges noncumulativity but risks ladder inflation; use explicit evidence fields, not a highest attained number. Selected positive examples and cropped stills are insufficient to infer shared meaning; include matched dramatic situations across works, alternative readings, documented failures and no-effect cases. Material shine, affective emphasis and semantic state may coexist without a single common semantic core. Radiance as comparison family is a hypothesis, not a demonstrated sign class. S02 motion cuts still open. Do not count sources or visual records as production validation.
- High: S04a is an actual source-controlled illustration/raster fixture, not semantic contrast validation. The four isolated patches are identical, but the final composites differ in underlying contrast, adjacency, eccentricity and salience; motif may be ambiguous. The label is assigned by the author after placement, not independently established meaning. No event/context counterfactual at same location, no audience data; no evidence that animation is required or unnecessary for these particular readings. Static construction is worth retaining. No need to force all atmospheric qualities into discrete cues, or demand participant experiments for every design decision; separate critical judgment from reception claims.
- High: original S04a assertions admit vacuous success. Original report says 250 support/changed pixels as observations, not asserted expected values. Missing base or motif can pass; anchor changes affect both test oracle and implementation. Overlay crop check tests separate rendering, not complete composited mark; file existence is weak. Actual mutation results below. RT01 older six P07 surviving defects remain unrepaired. No advancement to real production based on these tests.

## Measured background confound
Compute linear sRGB relative luminance of base and composite on changed RGBA pixels, average absolute difference. Values ornament .18230, field .40563, device .29605, UI .40959. Not a perceptual contrast metric or color-appearance model. Four same-support placements are not perceptually matched. A contrast-controlled patch with host context altered outside a common local neighborhood can supplement, not replace naturalistic artwork. Cross motif present/absent with context present/absent or swapped, control location and local background where feasible; avoid treating relative placement as sole cause without reception evidence.
