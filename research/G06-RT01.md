## Critical findings

- RT01 (critical, methodology): no bounded registered commercial/independent reference cuts, no matched target/control comparisons, no predeclared target-dependent artistic criteria. The branch has become an exercise in designing toy examples and verifying their own construction. R3 may apply to a narrowly declared reproducible fixture; no R4 production method, integrated R5 or charter C established. Existing 15 unmeasured atlas seeds are discovery records, not a comparative atlas.
- RT02 (high, actual adversarial test): P07 original JS harness executed in Chromium 144.0.7559.96 on original locally hash-matched source and eight one-at-a-time mutations. Baseline passes, 2/8 detected, all mutations error-free. This is a constructed mutation set, not an estimate of general defect coverage. See table below. Original implementation not claimed defective in these ways. Grid samples check the upscaler, not semantics; trace comparison reads the same precomputed object and cannot prove independent simulation. Probe threshold shows color at a few coordinates, not attribution, presence all ticks, spatial contrast or recognized meaning. 720 render calls are not independent assertions.
- RT03 (high, conceptual): vocabulary mixes state changes (attenuate, divide), temporal modifiers (delay, hold), relations (assign, layer) and research method (transpose). OP01/02/04/05 overlap without typed input, invariant or distinguishing counterexample. No composition rules or tests that catalogue predicts or improves artist decisions over plain storyboards. Do not implement a DSL or generalized editor. Retain as descriptive lexicon; split observational, compositional and production/meta levels; require out-of-family examples and conditions for revising a label.
- RT04 (high, artistic): three visually related families use a narrow palette, abstract geometry and isolated dark backgrounds. No observation of material behavior in actual footage, expressive contrast at fixed narrative event, hand-authored drawing in a real DCC, comparative labor, sound composition playback, dense scene stress or independent critique. P06 changes contour, path and exposure together; cannot infer technique-specific benefit. P07 context-specific branching is a meaningful prototype but not transfer across materially different expressive styles. The key target is visual authorship, not runtime scripting alone.
- RT05 (high, scope): G06 expansion was justified but can become open-ended. Stop accumulating source counts/operation names/vignettes until target selection and evidence gates are met. G07 remains deferred per user; review rather than automatically start it. Graphics-wide dimensions/style remain unapproved.
- RT06 (medium, custody): local P05 preview Git hash 5fe3fa9ceae2af8bcd846b8b6489c13bcae42044; P06 source 06672a74c15471553a8749ac18db7373393bd5f7 and archive 0fa4895e222f040ac24dbed251a95bdcfa208563; P07 preview 94275bcf3152ec5274f6832c31ca55bf54dc5a8b, all match recorded identifiers. ## Recovery gates (proposed; no universal standards)

1. A09: register three actual lawful target sequences plus negative comparators, spanning natural/material, directed fictional/interactive, nonliteral composition. Exact version/cut/time or frame interval/scale and provenance. Observe global support, internal morphology, direction, exposure, layer relationships and context; competing explanation and uncertainty. No download/redistribution without rights.
2. Select one demanding target and preregister observable visual properties, simpler baseline and acceptance/critique method. Reconstruct from independent original assets in a real authoring environment; match duration, display, path and semantic event when comparing representation. Record failures, authoring steps, measured revision effort and clean export. A second materially different target for transfer. Do not let aesthetic judgment rest on hashes or count of frames.
3. P07 validation repair: separate reference state expectation from renderer; all-tick active/nonactive masks or role pass plus composed-image checks; assert FX-on/off actually differs where intended and preserves critical cues; measure guard position/time independently; assert impact onset/offset and cancel suppression across surviving ticks, not only t18. Kill these six survivors plus positive controls without breaking baseline. Mutation set is regression minimum, not exhaustive coverage. Keep authored art evaluation separate.
4. Actual runtime: import one effect with named pivots, sheet/time metadata and blend contract; observe under scene/camera/overlap stress, live input cancellation and repeat/reset. Record production versions, settings, results, failure and rerun from clean checkout. Do not assume Effekseer mixed blends equivalent from scalar proof.
5. Branch review against original four gates; bounded stop/defer decisions. No new presets, taxonomy expansion or authoring-tool work before step 1 unless directly necessary.

This is a red-team report, not remediation of the original visual tests. Do not retroactively invalidate legitimate limited observations (e.g. P01 arithmetic, P06 palette and frame counts, P07 baseline render). Do not promote them beyond their scope.
