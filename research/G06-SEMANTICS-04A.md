## Host/dependency axis (proposed)

An effect may (1) be presented as an entity/phenomenon in its own right; (2) attach to an existing bearer, preserving its relative placement; (3) modify properties of an existing element or transition between representations of a persistent identity; (4) transform a region or composited scene/image. A relational effect such as tether has multiple bearers; shared-element transitions can couple outgoing and incoming surfaces. Hybrid usages are expected. Multiple effects may act on each other. Distinguish represented status (what it appears to be) from implementation (a mesh, separate overlay or shader may achieve the same result), coordinate/lifetime dependency and semantic role. E.g. projectile drawn by shader can be visually autonomous; an overlay can imply intrinsic material change; a fog object can alter scene register. Neither independent object nor host modification implies gameplay semantics. Classification not recovered as one historical taxonomy.

## S04a actual static experiment

The prior S04 draft set a shared motif, fixed composition and isolated attachment variation. Original SVG scene has a courier portrait, clasp ornament, sentinel, empty space and LINK interface control. One two-star motif definition, integer translations to four hosts/regions; same base, fixed 480x300 viewport, no motion. Context-only and isolated-motif controls; latter transparent in exported PNG and composited on flat color only for labeled plate. The different placements vary underlying contrast, eccentricity, adjacency and material; these are not all matched. Scene and intended readings assistant-authored, no user-approved art direction or exact commercial reconstruction. Source and result files [labs/G06-S04a](../labs/G06-S04a/). Rasterized CairoSVG 2.8.2, Pillow 12.3.0, NumPy 2.3.5. Run python render.py in lab folder; adapt Linux DejaVu Sans font path if needed for comparison plate. Source blobs c3ffbad44659a9997312aea8eab6ba9497c8ff7a, 0cfd33040ecb51ce22f1ba61e7de3fd683c5816e; observed results 4eff064d9011d528562bea6f654bbc36f02321f7, exact local hashes matched before commit. Binary PNGs and full archive provided in chat; not mirrored in repo.

For each placed motif, rasterize it alone and compare a 40x40 crop centered on anchor across variants. All crops are RGBA-identical. Each has 250 nonzero-alpha support pixels, 250 pixels changed compared with base, zero changes outside the motif support. Six unlabelled images exported (file existence check, not independent aesthetic validation). This verifies isolation of the added graphical mark, not recognition or meaning.

Intended readings: ornament/material brilliance, adjacent field/affect, aperture/activation or attention, UI/emphasis. Critique from actual contact sheet: field lies near smiling face, but smiles occur in every context and the star could also imply magic, noticing, or an ambient light. Aperture glint could be a reflection rather than a warning; interface glint could mean novelty, success or a recommended interaction. Ornament sparkle occupies much of small gem and could signify enchantment rather than gloss. The sparse highly legible static composition is a teaching/control fixture, not accomplished commercial illustration, and labels should not prime an audience evaluation. A static instance cannot establish whether the sentinel is active, nor does attaching the mark to a button demonstrate a transition. Meaning needs independent context/events or reception. Do not count this as S4, R4 production transfer or repaired RT01.
