# G06-P02 — Exposure as a compositional variable

Status: original isolated timing function executed in JS sandbox; authoring and perceptual studies not executed. No historical frame data. Linked to G06-A03 and G06.1–3.

## Semantic control

Seven ordered abstract radius poses [0,2,4,6,8,10,12] with three different exposure distributions, exactly 24 authoring ticks at 24 Hz. All pose values/order and endpoints shared; only durations differ. First and final poses carry explicit exposures. Output sampled at 60 Hz using floor(i*24/60), half-open tick windows. No interpolation. This is a one-second fixture and a scalar proxy, not actual drawings, perceived timing or historical convention.

| Variant | Hold counts in ticks | First radius >=10 (zero-based tick) | First radius 12 (tick) |
|---|---|---:|---:|
| impulse_then_settle | 1, 1, 1, 2, 3, 5, 11 | 8 | 13 |
| wait_then_release | 11, 5, 3, 2, 1, 1, 1 | 22 | 23 |
| uniform_control | 3, 4, 3, 4, 3, 4, 3 | 17 | 21 |

All six checks pass; all 7 poses appear at 60Hz, yet their presentation-frame counts differ. With the same source poses and time budget, the exposure schedule changes growth emphasis. The term uniform_control is near-uniform (3/4 alternating exposures), not exactly uniform. Names are descriptive hypotheses, not validated affective readings. The endpoint timing follows from the declared schedule; the control is a sanity test for a later comparison, not proof of a new perception law.

Run `node labs/G06-P02/timing_control.mjs`; same function executed in JS sandbox; Node CLI not independently run. See [results](../../labs/G06-P02/results.json).

## Proposed operator study

1. Observe a safely available flame video (or water pour and steam, not dangerous real-world explosion experiments). Register source/rights, duration, sampling and scale. Track whole silhouette, contour lobe movement, growth, splitting and disappearance. Identify what an individual drawing cannot express. No frame copying into public repo absent rights.
2. Create an original seven- to eight-pose primitive shape sequence in Aseprite, working at a local 64x64 fixture or chosen target resolution. Use rough circles/contours and directional arrows first; play them back before adding highlights or texture. Create one drawing library with exact exposure metadata; duplicate only timing, not drawings, for three treatments. Export a sheet and timing metadata and compare to a parametric equivalent with sample-and-hold; use 24Hz authoring grid and 60Hz host for this lab, verify actual durations rather than assume .aseprite metadata represents 1/24s exactly (millisecond quantization). Keep a tick-based exposure table as canonical for this study.
3. Add a second layer: first flash or ring, then a mass that separates and dissipates. Derive intentional relative timing: coincident onset vs lag; compare synchronized vs individually staggered tails. Match layer count, source assets, total duration and camera. Do not assume one schedule suits every context. Compare the same operation in a nonliteral graphic phrase to test contextual transposition.
4. Record source/exports, exposure chart, time curves, versions, holds/loops, timing against event markers, actual render fps, intended reading, competing interpretation and corrections. Test 1x native preview as well as final composed scale. Match viewing conditions; compare actual motion rather than static contact sheets alone.
5. Compare a hand-drawn contour treatment and a procedural primitive arrangement. Test a second different phenomenon for transfer. Document where extra in-betweens or manual contour corrections are needed.

Acceptance: exact pose order and duration within declared timing tolerance, no unplanned skipped pose at tested rate, recognizable continuity in actual playback as judged in documented critique (not inferred from numeric fixture), reasoned comparison of layers and exposure alternatives, reproducible revision. Do not claim measured viewer impressions without an appropriate study. No tool-specific claims from scalar control. G06 visual family and nonliteral atlas remain open.
