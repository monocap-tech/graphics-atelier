## Reproduction

Load local HTML with Playwright Chromium using page.set_content(Path("labs/G06-P05/preview.html").read_text()). Run [check.js](../../labs/G06-P05/check.js) inside that loaded page with page.evaluate and compare results; browser version and Canvas antialiasing may change exact mixed-block counts. Save images by calling renderAt and canvas.toDataURL, decode PNG bytes. Sample ticks 9,19,27,38 for each normal context; tick 22 for cancelled discharge/targeting. For an animation call every tick 0–47, arrange contexts as rows and representations as columns; nearest downsample if necessary. Preserve decoded pixels and exact tick schedule; GIF timing rounded to five 40 ms plus one 50 ms per six frames for total 2s.
