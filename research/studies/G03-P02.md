# G03-P02 — Articulated raster: independent transforms vs shared logical grid

Status: original procedural control executed in JS sandbox; editor/runtime study proposed. Domains VG02, VG07, VG08, links G02-P01 and G08. Local test dimensions only.

## Control

Original two-link rectangular fixture: root (12,12), link length 8 logical px, child rectangle attached at continuous transformed joint, child drawn last. Seven absolute orientations 0 to 90 degrees in 15 degree increments; child relative rotation fixed to zero for this control. Two color indices plus background. Inverse-transform output sample centers, test membership in each part's half-open rectangle. Compare direct 128x128 output sampling to sampling at 32x32 then replicating each texel into a 4x4 block. Neither path uses antialiasing or real texture import. Count mixed 4x4 output blocks relative to the logical grid; report total differing output pixels. Illustrate independent rounding by rounding the child pivot but not the parent endpoint (distance only, not a simulated visible gap). Correct registration check is by construction; not an independent rig validation.

All seven fixture checks passed: shared-grid alignment, matching axial controls, off-axis block splitting in direct output, analytic registration, fixed draw order at overlap, preserved 3-index palette and nonzero independent rounding displacement. Grid alignment of the replicated low-resolution path follows from its definition; this is a sanity check and counterexample to conflating color preservation with grid preservation, not quality evidence. The grid result does not establish temporal stability, superior silhouette, prevention of gaps in sampled artwork, or Unity/SpriteStudio equivalence.
