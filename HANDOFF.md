## Current cursor

It was assembled from preliminary investigation and earlier project discussions; it does not establish experimental results. The repository is public, so previously private material is not imported.

Next: G02-A02 acquire and measure a bounded set of lawful target captures, alongside G00-A02 independent raster instruction recovery; then create a small original specimen with declared acceptance and resource limits. Isolated G03 dimensions remain local experimental fixtures; no study is held up by the entire reference survey. The UI bridge is G08, not a reason to restart or silently replace any separate curriculum.

## Open decisions

- Which target/frame/sequence is first, and what counts as sufficient?
- Which original character specimen, identity cues, intended camera and procurement/handoff test best reveal the minimum viable sprite resolution? No external commission or purchase is authorized by this proposal.
- Which software versions are available to the researcher; what acquisition/labor budget is permissible?
- Which logical display, palette/texture, geometry and performance constraints are actually useful?
- What original specimens and measures will establish generalization and integration?
- Which publication framework and license, if any, are desired? Rights review precedes asset publication.

## Governance

Keep source facts, reconstruction hypotheses and measured findings separate. Record failed approaches and do not silently rewrite prior decisions. Prefer small reviewable changes. Do not conflate the independent graphics investigation with completing a course assignment or a finished game. Do not treat an R0 source registry as verified literature, or a proposal as a tested technique.
