# Graphics Atelier

Research and production laboratory for visual graphics architecture, interactive presentation, and authoring workflows.

**Purpose:** reconstruct the capacity to produce sophisticated original graphics and presentation using publicly obtainable knowledge, accessible tools, and independent-development resources. The work is target-led, not software-led. Historical fidelity is a research variable, not a universal requirement.

## Programme orientation (2026-11-20, proposed on a review branch)

Graphics Atelier studies the **relations between artistic intention, representation, perception, computation, production and presentation**, rather than any one studio's methods or a universal visual standard. "Minimum quality" means fitness for a *declared* artistic/use context and the capacity to construct, judge, revise and maintain that result—not fixed resolution, polygon, palette or performance thresholds. Historical exceptional practice is evidence, not an obligatory implementation.

## Research position

Commercial work supplies targets; primary production sources, independent reconstructions, and executable public experiments supply candidate mechanisms. Only repeated experiments under declared conditions establish a validated workflow here. Negative results are retained.

The production boundary includes acquiring or commissioning suitable editable artwork, adapting it to different visual representations, and maintaining an asset contract through runtime. The repository is independent of any single game. A hybrid shooting-game demonstrator is a prospective application, not a condition for starting research. The public [Relay Yard](https://github.com/monocap-tech/relay-yard) project provides a compact practical presentation case, with the migration caveats stated in its README.

**Status:** provisional foundation charter adopted 2026-11-17, G06 standardization 2026-11-18. Original bounded rendering/validation fixtures exist, but no general G06 R4 production method, human-response result or integrated TC-C demonstration is established. No engine, graphics budget, publishing framework or distribution license has been locked at the project level. Historical G06 REV01/REV02 priorities are superseded by STD01; G07 remains deferred.
